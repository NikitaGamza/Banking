# Приложение по анализу трат

Приложение по анализу расходов и получаемого кешбека за заданный период. 
Анализирует затраты по каждой карте; анализ категорий, по которым происходят 
наибольшие траты; а так же топы наибольших трат и наибольшего
кэшбэка.

Приложение содержит: 
- Приветствие пользователя.
- Чтение фала с банковскими данными. 
- Выбор периода для анализа данных. 
- Вывод статистики затрат по кадлой карте.
- Топ наибольших транзакций.
- Курс валют (доллар, евро).
- Курс акций.
- Сервис по анализу кэшбэка за указанный период.
- Отчёт по тратам в указанной категории.
